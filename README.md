# 🚗 ParkWise – Smart Parking System (Frontend)

> A smart parking web application designed for efficient management of parking in residential buildings. This frontend project includes separate login interfaces for residents and security, a clean dashboard UI, and real-time occupancy tracking components.

🔗 **Live Demo**: [https://parkwise-three.vercel.app](https://parkwise-three.vercel.app)

---

## ⚙️ Tech Stack

- ⚛️ React.js (Vite or CRA)
- 🎨 Tailwind CSS
- 🔄 React Router DOM
